# Weather Dashboard

A simple weather app built with vanilla HTML, CSS, and JavaScript. Search any city and get live temperature, conditions, and an icon using the OpenWeatherMap API.

## Features
- Live weather data via `fetch()` and `async/await`
- Error handling for invalid cities
- Loading state while fetching
- Custom dark "dusk sky" theme

## Setup
1. Clone the repo
2. Create a `config.js` file in the root with:
```js
   const apiKey = "YOUR_OPENWEATHERMAP_API_KEY";
```
3. Open `index.html` in your browser

## Tech
HTML, CSS, JavaScript, OpenWeatherMap API
